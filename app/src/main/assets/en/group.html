Group

Complete the unfinished Cayley table of a group

A Latin-square puzzle played with the multiplication tables of small mathematical groups. You are given a few entries of a group's Cayley table and must fill in the rest so that every row and column contains each element once and the table still obeys the group axioms (in particular associativity). The elements are shown as letters; in the default setting the first letter is the identity.

This puzzle comes from the "unfinished" folder of Simon Tatham's collection. It is fully playable but esoteric and can be hard.

Group controls

Tap a square and then a letter key to fill it in; tap the Clear key to erase it. Long-press a square to switch it to pencil-mark mode and tap letters to add or remove pencil marks. Tapping the selected square again deselects it.

Rows and columns of the table can be rearranged without changing the puzzle: drag a row or column header (the letters at the edges) to a new position. Dragging diagonally from a selected square selects several squares at once so that you can fill them with the same letter.

With a keyboard, the cursor keys move the highlight, Enter toggles pencil-mark mode and Space erases.

Group parameters

Grid size
The number of elements of the group, i.e. the size of the table (3 to 26). The group is chosen at random among those of that order.
Difficulty
Higher levels need more complicated reasoning, such as associativity.
Show identity
When set, the identity element is shown as the first letter; otherwise the letters carry no such hint.

Status

Fully playable. An extra preference keeps the highlight on a square after you change a pencil mark. The generator is fast at the preset sizes; the Hard level at order 8 can take a second or two. No logical next step is available.
